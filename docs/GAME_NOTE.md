# スーパーマリオワールド：ビンゴ設計用ゲーム調査ノート

調査日：2026-09-23。対象：日本版スーパーファミコン『スーパーマリオワールド』。

この文書は、お題と経路・所要時間の設計をレビューするための調査資料である。ゲーム仕様、競技ルール案、設計上の考察を区別する。コード、カタログ、経路設定の変更を指示・確定するものではない。

## 1. 調査範囲と確度

- **資料確認済み**：本文に出典を付けた配置、接続先、ゲーム内条件。主に任天堂説明書、Super Mario Wiki の個別コース記事、Thonky の攻略記述を参照した。
- **提案**：お題の達成条件、採否、同時配置の扱い、レビュー観点。ゲーム本来のルールとは別である。
- **未検証**：日本版SFCでの全候補の通しプレイ、所要時間、成功率、最短経路、全名称の実機照合。資料確認を実機検証済みとは扱わない。
- 想定する競技条件は、新規データ開始・バグ技なし。リセット、途中退出、中間地点再開、持ち込み装備、再挑戦の細則は未確定。
- 前回提案の30候補は番号を維持し、G01〜G30として記載する。25候補をそのまま1枚のカードにする提案ではない。
- 既存51件は一部を再評価した。51件すべてについて成立性を保証した監査ではない。

基本仕様の一次資料：[任天堂の日本語説明書][manual-ja]、[任天堂の英語説明書][manual-en]。細かな配置・分岐の根拠は各節に記す。二次資料にはSFC版とGBA版が併記されているため、版差のある数値はそのまま流用しない。

## 3. マップ構造の読み方

以下の表は**出口によって開く接続**を表す。地形の座標、開通後の全移動方向、マップ歩行の所要時間を網羅するものではない。

- 「通常」「隠し」はプレイヤー向けの呼び方。内部フラグの数値とは切り離す。
- 接続先に到達可能になることと、そのコースをクリアすることは別。
- 通常ゴールでも、新しいコースへ進まないことがある。
- 赤いコース点には複数の出口がある。おばけやしきはコース点の色だけでは判別できない。城・砦には独立した隠しゴールがない。[出口一覧][secret-exits]
- 「96」はコース数と同義ではない。全出口達成のお題を作る場合は出口単位の定義が必要。クッパ戦や特殊エリアを含めた集計細則は、別途日本版実機で照合する。[ゲーム全体][game]

「スペシャルへ入るには必ずネイティブスターの隠し出口を5つ全部通る」とは定義しない。**直接の入口開通条件はコース5の隠し出口**であり、コース5への到達経路は複数ある。[コース5][star5]

### 3.7 レビューで比較すべき代表経路

以下は到達可能性の説明であり、最速経路の実測結果ではない。

| 目的 | 代表的な経路 | 設計への影響 |
| --- | --- | --- |
| クッパ城へ早く向かう | ヨースター本線、ドーナツ1隠し、ひみつ1隠し、ボステレサ、ネイティブスター1〜4の隠し出口、クッパ城正面 | 城2〜7の全攻略を必須コストにしない |

## 4. お題に関係するゲーム仕様

### 4.1 スイッチ・収集・ボーナス

| 要素 | 資料で確認した仕様 | お題への含意 |
| --- | --- | --- |
| 大スイッチ | 黄・緑・赤・青の4つ。押すと同色の点線ブロックが実体化し、その宮殿は再入場できなくなる | 入場と作動を区別。宮殿内の別課題は作動前に済ませる必要がある |
| ドラゴンコイン | 同じコースで5枚集めると1UP。配置数をすべてのコースで5枚と仮定できない | 「全部」より「5枚」と対象コースを明記 |
| ボーナスブロック | そのコースでコインを30枚以上取ってから叩くと1UP。足りなければコイン | HUDの持ち越しコイン枚数だけでは判定しない。1UP出現・取得を証拠にできる |
| ゴールスターのボーナスゲーム | ゴールスターの累計100で入場。9ブロックを揃えるゲーム。最大8個の1UP | 「ボーナスに入る」はこのゲームか他の別室かを指定 |
| 土管内の3択部屋 | 3ブロックが5段。各段の正解順はランダム。SFCにはマントを使う確定取得のテクニックがある | 5個獲得を採るなら、テクニックの許可範囲を先に決める |

出典：[スイッチ宮殿][switches]、[任天堂説明書][manual-en]、[ボーナスブロック][bonus-block]、[ボーナスゲーム][bonus-game]、[3択部屋][oneup-room]。

| ピンクの木の実 | 同じコースで2個食べると雲が出現。雲のボーナスコイン10枚を全部取ると1UP。まよいのもり1にはピンク3個 |

| 青い子ヨッシーの育成 | ネイティブスター2開始地点のスターを食べさせると成長する |
| ヨッシーの翼 | チーズブリッジ、谷2、Way Coolに配置。騎乗して取ると上空エリアへ移動。SFC版はヨッシーが青になるが、GBA版は色を維持 |

「飛ぶ」はマント飛行、甲羅によるヨッシー飛行、翼のワープ、Pバルーンを分けて扱う。禁止条件では何を禁じるか列挙する。「全色」は一時的な翼の表示ではなく、成体の体色と騎乗を基準にする案を推奨する。

## 5. ビンゴ候補30件

### 5.1 判定の共通ルール案

1. 「取る」は出現させるだけではなく取得まで。「乗る」は成体への騎乗まで。
2. G14〜G16のドラゴンコインは、コース先頭からの1回の入場中にミスせず5枚。取得後のゴールは不要。中間再開による持ち越し・再取得を含めない。
3. 複数個の取得・撃破を1コースで求めるG19・G23・G24・G27・G29も、1回の入場中に満たす。G26・G25はレース開始からの累積。
4. 制限付きクリアG28は、コース先頭からゴールまで条件を維持する。条件違反後の部分的なやり直しでは達成にならない。
5. 取得系は達成した時点で確定とする案。後のミスで取消すルールにする場合は全候補で統一する。
6. 「道を開く」は対象出口でゴールし、マップの接続が有効になったことまで。既に別方向から接続済みの場合に備え、実際に通る出口も指定する。

これは競技ルール案であり、採用前に合意が必要。以下の「負担」は定性的な評価で、`timeMin`、`exec`、`risk`の実測値ではない。

## 6. 候補同士の依存・同時達成・競合

以下はゲーム仕様からの設計上の考察。配置禁止ルールとして確定したものではない。

| 組み合わせ・条件 | 関係 | レビュー観点 |
| --- | --- | --- |
| G06とG16・G20・G21・G26 | 星1側から入る場合、G06が道中に含まれる | 代替入口もあるため、全経路共通の必須依存とはしない |
| G20とG26 | G20で青の騎乗が満たされる | 個別目標と全色目標の部分包含 |
| G22とG26 | SFC版の翼取得で青色を得られる | 青ヨッシーの調達を星2だけに固定しない |
| G07とG22 | 同じチーズブリッジだが異なる終了ルート | 翼の上空ルートはコース終了につながるため、1回で両方達成する前提にしない |
| G14とG24 | 同じヨースター4、主に別の取得対象 | 同じ入場で組み合わせ得る。道中重複と作業重複を区別 |
| G11と序盤の装備調達 | ヨースター1へ後から戻る場合がある | 地域の順番だけでは移動・準備時間を表せない |
| G17とG13 | バター側とチーズ側の別枝 | バニラ地域全体を1つの共通時間として差し引かない |
| G08とチョコレー本線のお題 | 城6への短絡経路と本線攻略 | 単独最短ルートの単純な合併が最短になるとは限らない |
| G10・G30とクッパ撃破 | お題が城への接続・入口選択を兼ねる | クッパまでの固定時間を丸ごと追加すると過大評価し得る |
| スイッチ作動と宮殿内の別課題 | 作動後は再入場不可 | 先に作動すると別課題を失敗状態にできる。恒久的な相互排他ではなく実行順序の制約 |
| G25と鍵ゴール中心のルート | ゴールスターの稼ぎ方が異なる | 同じコース数・出口数でもG25の進捗は同じにならない |
| G28とG29 | スペシャル8番目へは2番目を通る | 通常クリアは道中でも、G28の騎乗禁止まで自動成立するわけではない |

翼エリアからの終了については[ゲームのエリア説明][game]、その他の根拠は各候補の出典を参照。

同一コースのお題を同じラインへ重ねない方針は有効だが、別コース間の包含関係までは防げない。逆に「同じworldはすべて禁止」だけでは、分岐の異なる経路を適切に評価できない。

## 8. 現行資料を踏まえた設計レビュー論点

この節は調査結果の適用先を示すもので、実装の動作確認結果ではない。参照したローカル資料：[分布設計](bingo-distribution.md)、[名称一覧](LEVEL_LIST.md)、[経路区間設定](../backend/bingo/route_segments.json)。

### 8.1 地域と到達経路

現行の区間設定には `vanilla:common`、`vanilla:cheese`、`vanilla:plateau`、`plateau:butter` があり、バニラの分岐を分ける方向はマップ構造と対応する。ただし `vanilla:common` の説明が「コース1（共通）」であるため、コース1をどの地点まで共有とするかは明確化が必要。通常出口・隠し出口の両方を通る費用まで1回分にしない。

同様の検討が必要なのは、ドーナツ通常／星方面、森の城／とりで方面、チョコレー本線／ひみつ、谷の正面／裏口、星の複数入口。エリア名が同じというだけで、同じ道中を通ったと判定しない。

### 8.2 所要時間

`bingo-distribution.md` は `timeMin` を開始から単独達成まで、`routeAreaTimes` を区間単体の時間としている。ゲーム仕様を当てはめる際は次を分けて計測する必要がある。

- 初回解放に必要なコース・出口の攻略。
- 開通済みマップ上の移動と再入場。
- 装備・ヨッシーの調達、持ち込み不可地点、失った場合の再調達。
- お題そのものの作業と、同一入場で共有できる作業。
- お題終了後からクッパ撃破までの残りの経路。

単独最短のお題時間を加算して共通区間を引く方法は近似としてレビューする。別々の最短経路が同じ装備・出口履歴で両立するとは限らない。今回の資料だけでは分単位の値、成功率、最速ラインを確定できない。

### 8.3 クッパまでの固定費用

既存資料は「1ライン達成＋クッパ撃破」を基本ルールとし、`baseRoute` を固定加算する。ゲーム側には星経由・地上本線・裏口という選択がある。G06、G10、G30などが到達の一部を兼ねるため、固定加算値が何を含むかをレビューすべきである。

「ゲーム開始からクッパまで」と「各お題達成後からクッパまで」は別の値。前者を、開始からのお題時間へ無条件で足すと重複が生じ得る。この文書では計算方式の置換案を確定しない。

### 8.4 判定と不可逆な進行

お題の記録単位は、少なくとも出口達成、アイテム取得、累積取得、条件維持クリアを区別してレビューする。例えばG21は最終的なマップだけでは雲の使用を証明できず、プレイ過程の確認が必要。G26も最終状態のヨッシー1色だけでは全色騎乗の履歴を証明できない。

宮殿作動後の再入場不可、同一ムーンの再出現、途中退出・ミス時の取得履歴は競技の細則に影響する。ゲームのセーブ状態と、ビンゴ上の達成記録を同じものとみなさない。
