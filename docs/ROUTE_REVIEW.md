# 道中とクッパ撃破時間の見直し（2026-09-23）

対象はSFC版スーパーマリオワールドの通常のコース接続。下記資料で接続・ゴール条件を確認した。実機の所要時間は未計測であり、資料上の接続と分単位の実測値は分けて扱う。

## 確認した誤り

- 森3の隠しゴールは城5へ直接接続する。「隠しゴールから城5へ」という独立した攻略区間は不要。隠しゴールの攻略自体は森3のお題時間に含める。[森3](https://www.mariowiki.com/Forest_of_Illusion_3)
- 谷2の隠しゴールはとりでへ接続し、とりでをクリアして初めて裏口が開く。谷2から裏口までを単なる移動と扱わない。[谷2](https://www.mariowiki.com/Valley_of_Bowser_2)、[裏口](https://www.mariowiki.com/Back_Door)
- バニラ1は通常ゴールがコース2、隠しゴールがひみつのコース1へ接続する。分岐前だけを両ゴールに共通の一回分として控除しない。両ゴールを必要とする場合はそれぞれの攻略を数える。[バニラ1](https://www.mariowiki.com/Vanilla_Dome_1)
- バニラの上側はひみつ1通常ゴール・2・3・とりでを攻略してバターブリッジへ進む。ひみつ1の隠しゴールはスター2方面であり、上側の攻略とは異なる。[橋エリア](https://www.mariowiki.com/Twin_Bridges)、[ひみつ1](https://www.mariowiki.com/Vanilla_Secret_1)
- ドーナツのひみつのおばけやしきでボステレサを倒すとスター1へ進める。スターの道を進めるのは隠しゴール。スター4の隠しゴールで城の正面へ通じる入口が開く。[ひみつのおばけやしき](https://www.mariowiki.com/Donut_Secret_House)、[スター](https://www.mariowiki.com/Star_World)、[スター4](https://www.mariowiki.com/Star_World_4)
- 城の正面は城7クリアでも到達できる。裏口は城内の前半を省略するがクッパ戦は同じ。正面・裏口は、城への道中と城内の時間を区別する必要がある。[正面](https://www.mariowiki.com/Front_Door)、[裏口](https://www.mariowiki.com/Back_Door)

8候補は全経路を網羅しない。チョコレー・スペシャル等は、測定済みの共有単位を登録していなければ、お題の開始から達成までの時間に含めたまま扱う。単なる地域一致では控除しない。まとまりの途中にあるお題や別入口から入るお題に、全区間の控除を適用してはいけない。たとえばスター2入口からの道中にスター1〜4全体の補正は使えない。

## 計算と既存データ

- お題の `timeMin` は引き続き新規開始から単独達成までの時間。全ゴールを攻略する同一のまとまりを選んだお題どうしだけ、測定済みの攻略時間を重複控除する。開通済みマップ移動、再入場、装備再調達は共有の攻略時間から除外する。
- 旧30定義は、範囲が曖昧なものと細分化しすぎたものを含む。値と参照は保存互換のため内部に保持するが、旧設定の参考欄は表示せず、新しい補正から除外する。新8定義へ旧分数をコピー・合算しない。旧定義を参照した抽選対象のお題は管理画面で選び直す。保留中のお題は旧参照を保持できる。
- 新定義は未計測なので空欄。時間の範囲・粒度が変わるため、今回の調査だけで数値を決めない。
- クッパ補正は任意。新規開始から撃破までの実測合計から、お題と共有するまとまりの攻略時間だけを一度引いて加える。正面／裏口の城内攻略・戦闘・再移動を残す。複数の実測経路があればラインごとに最小の見積もりを使う。
- 未登録時は既存の固定加算（既定15分）を維持する。この15分は今回の調査で検証した値ではない。1ラインのみのルールには加算しない。
- 現在地・装備・移動順を追跡する自動経路計算はしない。最短時間・完走可能時間を保証するモデルではなく、現時点では未計測の暫定見積もり。

管理画面では道中補正とクッパ補正を折りたたみ、通常のお題編集を先に行えるようにする。既存のクッパ実測設定がある場合は、その欄を開いて表示する。

## まよいのもりの接続と計算範囲

ここでの「ゴール」は英語の Exit に対応し、通常ゴールと隠しゴールを区別する。コース内の土管・扉の出入りとは別の概念。

城4をクリアすると森1へ進む。次の表は各ゴール・ボス撃破によって開く接続を表す。接続後のマップ上の往復移動を一方向に制限する意味ではない。

| コース | 通常ゴール・クリア | 隠しゴール | 資料 |
| --- | --- | --- | --- |
| コース1 | コース2 | おばけやしき | [接続先](https://www.mariowiki.com/Forest_of_Illusion_1) |
| コース2 | コース3 | 青スイッチのきゅうでん | [接続先](https://www.mariowiki.com/Forest_of_Illusion_2) |
| コース3 | おばけやしき | 城5 | [接続先](https://www.mariowiki.com/Forest_of_Illusion_3) |
| おばけやしき | コース4 | コース1へ戻る | [接続先](https://www.mariowiki.com/Forest_Ghost_House) |
| コース4 | コース2へ戻る | ひみつのコース | [接続先](https://www.mariowiki.com/Forest_of_Illusion_4) |
| ひみつのコース | とりで | なし | [接続先](https://www.mariowiki.com/Forest_Secret_Area) |
| とりで | スターロード（ネイティブスター4側） | なし | [接続先](https://www.mariowiki.com/Forest_Fortress) |
| 城5 | チョコレーとう コース1 | なし | [接続先](https://www.mariowiki.com/Roy%27s_Castle) |

- 森1通常→森2通常→森3隠し→城5が、森1から城5へ向かう経路の一つ。森3隠しから城5の間に別のコース攻略はない。城5の攻略時間は別に必要。
- 森1隠し→おばけやしき通常→森4隠し→ひみつのコース→とりでの経路では、森2・3の攻略は不要。森3通常からおばけやしきへ到達する別経路もある。
- 森2→3→おばけやしき→4→2は通常ゴールによる循環。おばけやしきの隠しゴールも森1へ戻る接続で、城5やとりでへの直接の近道ではない。
- とりでクリアはスター4側への接続を開く。城5クリアによるチョコレーとうへの進行とは別。星入口を利用しただけで森全体の道が解放されるとは扱わない。
- 森の到達経路は `forestSegments` の接続から、森1を起点として到達先までの循環しない候補を列挙する。管理画面で選ぶと必要な攻略ゴールのIDを `routeAreas` に保存する。到達先のコース自体の攻略は含めない。森への到達以前の設定は保持する。
- 森の時間は入場から各ゴールまでを個別に実測する。使用するゴールが未計測なら保存前に入力を求める。既存のお題に経路を推測で付けず、timeMinも選んだ経路を通る場合の実測値として設定する。
- 計算では同一ゴールIDの時間だけを重複控除する。クッパの実測経路と共有するときも同じIDで一度だけ控除する。通常・隠しゴールの違い、森3から城への直結、森4からひみつコースを経由するとりで到達を区別する。
- 複数候補からライン全体の最適経路を自動選択するものではない。保存時に選んだ経路を使用する。森1以外からの進入や複数ゴールを達成するお題は、攻略ゴールを個別に選ぶ。既存の地域別同時配置制約は維持する。
- 森1の通常と隠しは別ゴールなので、城方面ととりで方面の二つの経路を「同じ森1を通る」だけで一回分にまとめない。計測なしに「森共通○分」や「森3→城○分」を足さない。

森の基準時間は一般の8項目と分けた折りたたみ欄に集約する。森の13ゴールはコース攻略の単位であり、マップ上の移動を追加課金する項目ではない。未使用のゴールは空欄で保存できる。経路の再選択時は森の設定だけを置き換え、他の道中設定は維持する。
